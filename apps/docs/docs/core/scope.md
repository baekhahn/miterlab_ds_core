# P1 / P2 / P3 Scope

## Scope Levels

- `P1`: source-of-truth alignment, parity, freeze review 대상
- `P2`: P1 freeze 이후 확장 대상
- `P3`: 이후 확장 또는 adapter/theme 레이어 대상

## Current Rule

- P1이 끝나기 전에는 P2를 시작하지 않습니다.
- P2가 정리되기 전에는 P3를 시작하지 않습니다.
- scope 변경은 spec 변경보다 먼저 문서에서 선언되어야 합니다.
