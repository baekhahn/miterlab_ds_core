# P2 Families

P2는 P1 freeze 이후에만 시작할 수 있는 다음 확장 범위입니다.

## Rule

- P1 전체가 정의된 gate를 통과하기 전에는 시작하지 않습니다.
- P2는 additive extension만 허용합니다.
- P2가 core contract를 다시 바꾸는 방식으로 진행되면 안 됩니다.

## Current State

- 현재 문서 기준으로 P2는 대기 상태입니다.
- 시작 조건은 [Freeze Rule](/freeze-review/freeze-rule)과 [Freeze Review Status](/freeze-review/status)에 따릅니다.
