# Families Overview

이 섹션은 AI가 바로 구현에 사용할 핵심 family contract만 제공합니다.

| Family | Purpose | Inspection screen |
| --- | --- | --- |
| Button | 주요 액션과 보조 액션의 우선순위를 드러내는 core action family입니다. | `button-inspection` |
| Input | 텍스트 입력과 폼 데이터 수집을 담당하는 core text entry family입니다. | `input-inspection` |
