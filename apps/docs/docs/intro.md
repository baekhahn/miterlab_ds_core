# Core Overview

## Purpose

플랫폼에 구애받지 않는 모바일용 core design system 기준 문서입니다.

## Current Source

- Button source reference: [Tamagui Bento Buttons](https://tamagui.dev/bento/elements/buttons)
- Input source reference: [Tamagui Bento Inputs](https://tamagui.dev/bento/forms/inputs)
- 현재 source는 prop API가 아니라 Bento pattern bundle 기준입니다.

## What Core Means

- core는 구조 계약입니다.
- theme는 시각 오버라이드입니다.
- generator는 spec만 읽습니다.
- plugin은 payload를 flatten하지 않습니다.
- Figma는 output입니다.

## Layers

1. Foundation
2. Interaction Rules
3. Component Contracts
4. Pattern Contracts

## Fixed

- semantics
- structure
- interaction rules
- accessibility minimum

## Not Fixed

- framework API
- pixel implementation
- theme values
