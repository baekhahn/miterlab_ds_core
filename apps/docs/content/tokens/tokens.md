# Tokens

Miterlab 토큰은 세 레이어로 나눕니다.

1. Foundation: 제품 공통 스케일
2. Semantic: UI 의미 토큰
3. Brand(Project): 프로젝트별 브랜드 오버라이드

## 사용 순서
- 컴포넌트는 `semantic`을 직접 사용
- 프로젝트 적용 시 `brand`를 통해 semantic 일부를 매핑

## 대표 semantic 키
- `background.default`
- `surface.raised`
- `border.default`
- `text.primary`
- `icon.default`
- `action.primary`
- `focus.ring`
- `status.critical`
