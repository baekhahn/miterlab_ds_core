# Screen Patterns

v1에서 지원하는 화면 패턴입니다.

## Patterns
- login
- settings
- list
- dashboard
- detail
- filter-panel
- empty-state
- modal-form

## Pattern Includes
각 패턴은 다음을 정의합니다.
- required sections
- optional sections
- expected components
- layout flow

## Example
`login`:
- required: header, form, footer
- expected: title, subtitle, email/password input, primary action
- flow: header -> form -> footer
