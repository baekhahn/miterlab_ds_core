# Spacing Scale

Miterlab core backbone uses a tight, repeatable spacing system inspired by modern SaaS interfaces.

## Canonical Scale
- `4`
- `8`
- `12`
- `16`
- `20`
- `24`
- `32`
- `40`
- `48`
- `64`

## Backbone Usage
- inline micro gap: `4-8`
- label to control: `8-12`
- field to field: `12`
- form group gap: `16`
- section gap: `24-32`
- page top break: `40`
- major breathing space: `48-64`

Wanted is used only as a rhythm reference. Miterlab keeps its own tokens and generator logic.
