# Component Variant Rules

v1 컴포넌트 variant 축 규칙입니다.

## Allowed Properties
- `variant`
- `size`
- `state`

필요 컴포넌트에만 허용:
- `selected` (FilterButton)

## Allowed States
- `default`
- `hover`
- `pressed`
- `disabled`
- `focus`

옵션 상태:
- `error`
- `selected`

## Not Allowed (v1)
- `tone`
- `intent`
- `mode`
- `density`
- `level`
- `styleType`

## Rule
- 새 축이 필요하면 먼저 spec 문서를 변경하고, 이후 Figma에 반영합니다.
