# Fix Suggestions

평가 결과의 이슈 코드 기반으로 자동 개선 제안을 제공합니다.

## Example Suggestions
- primary action을 action 영역으로 이동
- foundation/brand 직접 참조를 semantic 변수로 교체
- 중복 section 제거
- variant/state를 지원 값으로 정규화
- section spacing을 density 규칙에 맞게 조정

## Usage Rule
- 자동 제안은 우선순위 힌트입니다.
- 실제 수정은 spec/grammar 규칙을 기준으로 확정합니다.
- 제안 적용 후 재평가를 반복해 품질을 안정화합니다.
