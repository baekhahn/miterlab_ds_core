# Design Production Workflow

실제 디자인 작업 흐름입니다.

## Standard Flow
1. token change 확인
2. semantic 영향 확인
3. spec 업데이트
4. Figma 변수/스타일 업데이트
5. Figma 컴포넌트 업데이트
6. docs 동기화

## Practical Rule
- token 변경 없이 스타일만 수정하지 않음
- spec 없는 variant를 Figma에서 임의 추가하지 않음
- 프로젝트별 차이는 brand/theme mode에서만 반영

## Lightweight Principle
- 복잡한 승인 체계 없이 문서 기반 합의
- 최소 체크리스트로 빠르게 운영
- 변경 이력은 문서/PR로 추적
