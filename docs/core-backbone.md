# Core Backbone

`core`는 브랜드가 입혀지기 전의 Miterlab 기본 뼈대입니다.

## Principle
- `core`는 중립적이어야 하지만 미완성 상태여서는 안 됩니다.
- 화면은 brand 없이도 정렬, spacing, hierarchy가 안정적으로 보여야 합니다.
- theme는 `core` 위에 색과 강조를 얹는 레이어입니다.

## Backbone Rules
- mobile frame width: `390`
- default content width: `358`
- frame horizontal padding: `16`
- frame top padding: `40`
- section gap: `32`
- form gap: `16`
- action gap: `24`
- control heights: `40 / 48 / 56`

## Reference Direction
Wanted Design System은 spacing, rhythm, control proportion의 참고점으로만 사용합니다.
Miterlab은 자체 token, semantic, generator 구조를 유지합니다.
