# Layout Rhythm

`core` 화면은 단순히 토큰을 배치하는 것이 아니라 일관된 리듬을 가져야 합니다.

## Default Rhythm
- header -> form: 명확한 분리
- form fields: 동일 폭, 동일 높이, 일정한 세로 간격
- action area: form보다 약간 더 큰 분리 간격
- empty footer는 만들지 않음

## Login Baseline
- title는 화면 상단에 고정된 여백으로 시작
- 입력 필드는 full content width를 사용
- 버튼은 field와 동일 폭을 사용
- title, field, button은 모두 동일한 좌측 정렬선을 공유

## Goal
브랜드를 입히기 전에도 화면이 서비스 제품용 기본 화면처럼 보여야 합니다.
