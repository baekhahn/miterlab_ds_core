# Prompt Screen Scope

현재 prompt-to-layout 변환기의 지원 범위입니다.

## Supported (v1)
- login
- settings
- list view
- filter panel
- detail page
- dashboard

## Not Yet Supported
- 복잡한 마케팅 랜딩 페이지
- 비정형 에디토리얼 레이아웃
- 일러스트/브랜드 아트 중심 화면
- 복잡한 반응형 분기 레이아웃

## Scope Rule
- 변환기는 deterministic 규칙 기반으로 동작
- 자유형 디자인 생성 AI가 아님
- spec/tokens/theme 규칙을 지키는 화면만 생성 대상
